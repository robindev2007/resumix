## 📚 Technical Interview Preparation Questions

<details>
<summary><b>1. Why use ClickHouse alongside PostgreSQL in an AdTech system?</b></summary>

> **Answer:** PostgreSQL is an OLTP (Row-oriented) relational database ideal for transactions, user accounts, and billing records where ACID compliance is vital. ClickHouse is an OLAP (Columnar) database designed for real-time aggregation across billions of rows (e.g. ad impressions, clicks, event streams) with 10x-100x faster analytical query execution.
</details>

<details>
<summary><b>2. Why is Go (Golang) preferred for AdTech Real-Time Bidding (RTB)?</b></summary>

> **Answer:** RTB auctions must respond within strict latency windows (typically < 50-100ms). Go provides ultra-fast compiled performance, lightweight goroutines for handling tens of thousands of concurrent connections with minimal memory overhead, and predictable garbage collection.
</details>

<details>
<summary><b>3. What is OpenRTB and how does an SSP communicate with a DSP?</b></summary>

> **Answer:** OpenRTB is an IAB standard protocol for programmatic advertising. When an ad slot loads on a publisher's site, the SSP sends a `BidRequest` JSON payload to multiple DSPs. DSPs evaluate targeting and reply with a `BidResponse` containing price and ad markup within milliseconds.
</details>
