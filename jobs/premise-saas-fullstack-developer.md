## 📚 Technical Interview Preparation Questions

<details>
<summary><b>1. What is the difference between stateful and stateless REST APIs in SaaS applications?</b></summary>

> **Answer:** In a stateless REST API, each client request contains all necessary information (authentication tokens like JWT, parameters) to process it without relying on server-stored session memory. This allows SaaS applications to scale horizontally across multiple instances seamlessly.

</details>

<details>
<summary><b>2. How do you design a database schema for multi-tenant SaaS?</b></summary>

> **Answer:** Common multi-tenancy approaches include: (1) Shared Database with Tenant ID column (most cost-effective and common for entry SaaS), (2) Separate Schemas per tenant (balance of isolation and resource sharing), or (3) Separate Databases per tenant (highest isolation for enterprise/HIPAA/financial compliance).

</details>

<details>
<summary><b>3. How do you leverage AI tools like GitHub Copilot effectively without compromising code reliability?</b></summary>

> **Answer:** AI tools are great for boilerplate, regex, unit tests, and API doc generation, but all generated code must undergo human verification, strict TypeScript typing, security sanity checks, and automated unit/integration tests before merging.

</details>
