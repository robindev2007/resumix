## 📋 New Job Posting Template (Copy & Paste for New Posts)

To log a new opportunity, create a new markdown file in `d:\cv\jobs\<company-name>-<role>.md`:

```markdown
# 📌 Job Research: [Company Name] — [Role Title]

## 🏷️ Quick Overview

| Attribute                    | Details                                               |
| :--------------------------- | :---------------------------------------------------- |
| **Company**                  | [Company Name] ([Website](https://...))               |
| **Role Title**               | [Role Title]                                          |
| **Experience Level**         | [e.g., Fresh Graduate / Junior / Mid]                 |
| **Location**                 | [Location & Office Address]                           |
| **Work Mode**                | [On-site / Hybrid / Remote]                           |
| **Application Deadline**     | [Date e.g., DD Month YYYY]                            |
| **Original Post URL**        | [Link to post]                                        |
| **Application Form / Email** | [Apply Link / Email]                                  |
| **Status**                   | `📝 Ready to Apply` / `⏳ In Progress` / `✅ Applied` |

## 💰 Public Salary Research & Benchmark

- **Estimated Monthly Range:** ৳XX,000 – ৳XX,000 BDT
- **Source:** [Glassdoor / Payscale / Market research]
- **Benefits:** [Festival bonus, Medical, Snacks, Remote stipend, etc.]

## 🛠️ Required Tech Stack

- **Languages:** [e.g., JavaScript, TypeScript, Go, Python]
- **Frameworks:** [e.g., React, Next.js, Express, Django]
- **Databases & Cache:** [e.g., PostgreSQL, MongoDB, Redis]
- **Cloud / Tools:** [e.g., Docker, AWS, Git, AI tools]

## 🎯 Key Responsibilities

1. [Responsibility 1]
2. [Responsibility 2]

## 🚀 Application Action Items

- [ ] Tailor CV for keywords: `[Key skill 1]`, `[Key skill 2]`
- [ ] Update portfolio projects
- [ ] Submit application before [Deadline Date]
```
